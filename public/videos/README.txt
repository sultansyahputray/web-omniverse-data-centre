# Power Simulation Videos
Silakan letakkan 3 file video simulasi kelistrikan di folder ini dengan nama:
1. `power_normal_flow.mp4` -> untuk tab Normal Flow
2. `power_simulated_flow.mp4` -> untuk tab Simulated Flow
3. `power_load_flow.mp4` -> untuk tab Load Flow

File-file di folder `public/videos/` ini akan otomatis disajikan oleh web dev server di URL:
- `/videos/power_normal_flow.mp4`
- `/videos/power_simulated_flow.mp4`
- `/videos/power_load_flow.mp4`
